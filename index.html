名單資料設定

{ "updatedAt": "2026-09-07 10:00", "sessions": [ { "date":"2026-09-21", "name":"第一梯次", ... } ], "people": [ { "name":"王小明", "id":"A12345", ... } ] }

之後會由 Apps Script 自動產生並更新 roster.json，你就不必手動上傳。
